# 桌面设备登录会话

`accounts.0005_desktop_session` 新增桌面会话表，每个已登记设备最多一个会话。
迁移只建表与索引，无须回填用户、设备或令牌。先执行常规 Django `migrate`，
再启用新版 API。支持持久登录的客户端可以在已有登录仍有效时登记会话，
或者在下一次登录时建立会话。服务端只保存会话密钥的哈希。

桌面会话使用现有短期访问令牌配置。会话密钥用于静默续期，有效期从最近
一次有效活动算起，满七天未活动后要求重新登录。提交云端聊天总结和修改
待办会记录活动。心跳、静默续期、后台备份及纯本地操作不会延长会话。
桌面退出登录、撤销设备或同一设备重新登录都会使原会话凭证失效。

如需回滚应用，保留新表可避免丢失会话。已切换到设备会话的客户端续期
依赖新版接口，回滚后接口恢复前无法静默续期。
